About PodFinder

PodFinder aggregates events from local game stores so you can find a Commander pod (or a draft, a league night, a board game meetup…) without checking five different store calendars.

How it works

  1. Each store gets an event source — usually the ICS calendar feed their website already publishes (Google Calendar, Squarespace, and Wix all expose one).
  2. A sync job refreshes each feed at most once a day into a local cache — browsing never hits store websites directly. It expands recurring events and classifies each one by game and format from its title — "Wednesday Night EDH" becomes Magic: The Gathering / Commander / Casual.
  3. Everything lands in one database you can filter by game, format, date, store, and distance — enter a ZIP code or use your browser's location, pick a radius, and browse the list or the map. Any filtered view can be exported as an iCal feed to subscribe to.

Adding your local stores

Edit data/stores.sample.json with your real local stores and their calendar URLs, then run python -m app.seed followed by python -m app.ingest.sync.
